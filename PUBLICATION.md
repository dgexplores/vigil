# Source provenance and publication

This is an attributed portfolio extension of the upstream project linked in the
README. The upstream contributors, file notices and commit authors are retained.
Before publication, inherited credential strings were redacted throughout Git
history. NeuroAgent's generated vendor layer and old demo-media directory were
also excluded from the public history. Commit hashes therefore differ from the
original repositories. The original local clones are preserved separately.

A full-history Gitleaks scan of this publication copy reported no leaks on
22 October 2026. No real signing secret, model key or cloud credential is needed
for the offline tests. Create your own credentials outside Git when configuring
an approved cloud environment. No cloud deployment or upstream award is claimed
as a new accomplishment in this extension.
